# 이우경 LAB 홈페이지 — 수정 안내

홈페이지 주소: **https://lwk-lab.github.io**

## 내용 수정하기 (구성원·연구 주제·연락처·소식 등)

1. 이 저장소에서 **`_config.yml`** 파일을 클릭합니다.
2. 오른쪽 위 **연필 아이콘(Edit this file)** 을 누릅니다.
3. 한글 텍스트를 고칩니다. (콜론 `:` 왼쪽의 영문 이름과 들여쓰기는 그대로 두세요)
4. 오른쪽 위 **Commit changes…** → 다시 **Commit changes** 를 누릅니다.
5. 1~2분 뒤 홈페이지에 반영됩니다. (브라우저 새로고침)

### 자주 하는 수정

| 하고 싶은 것 | 방법 |
|---|---|
| 연구실 이름 바꾸기 | `lab:` 아래 `name:` 값 수정 |
| 구성원 추가 | `members:` 아래 `- name:` 으로 시작하는 덩어리 하나를 복사해 붙이고 내용 수정 |
| 구성원 삭제 | 해당 `- name:` 덩어리를 통째로 삭제 |
| 졸업생 표시 | `role: 석사 졸업` / `role_en: Alumni` 처럼 역할만 바꾸면 됨 |
| 연구 주제 바꾸기 | `research:` 아래 `title:` / `desc:` 수정 |
| 소식 올리기 | `news:` 맨 위에 `- date:` / `text:` 덩어리 추가 |
| 이메일 표시 | 구성원의 `email: ""` 를 `email: abc@univ.ac.kr` 로 |

### 주의

- 값에 콜론(`:`)이나 샵(`#`)이 들어가면 따옴표로 감싸세요. 예: `desc: "주제: 머신러닝"`
- 수정 후 홈페이지가 바뀌지 않으면 저장소 상단 **Actions** 탭에서 빨간 X가 있는지 확인하세요. 빨간 X는 `_config.yml`의 들여쓰기나 따옴표 오류입니다. 파일을 열어 방금 고친 부분을 다시 확인하면 됩니다.

## 디자인 수정하기

색상·글꼴·배치는 `index.html` 에 있습니다. 상단 `<style>` 안의 `--accent:#1f4e79` 가 포인트 색상입니다.

## 파일 설명

| 파일 | 역할 |
|---|---|
| `_config.yml` | **홈페이지 내용** (여기만 고치면 됨) |
| `index.html` | 디자인 틀 |
| `robots.txt`, `sitemap.xml` | 검색엔진용 |
| `README.md` | 이 안내문 |

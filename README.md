# 이우경 LAB 홈페이지 — 수정 안내

홈페이지 주소: **https://lwk-lab.github.io**
소속: 서울사이버대학교 대학원 상담·임상심리학과

## 내용 수정하기

1. 이 저장소에서 **`_config.yml`** 파일을 클릭합니다.
2. 오른쪽 위 **연필 아이콘(Edit this file)** 을 누릅니다.
3. 한글 텍스트를 고칩니다. (콜론 `:` 왼쪽의 영문 이름과 들여쓰기는 그대로 두세요)
4. 오른쪽 위 **Commit changes…** → 다시 **Commit changes** 를 누릅니다.
5. 1~2분 뒤 홈페이지에 반영됩니다. (브라우저 새로고침)

## 자주 하는 수정

| 하고 싶은 것 | `_config.yml`에서 고칠 곳 |
|---|---|
| 다음 세미나 날짜 알리기 | `next_meeting:` 값 수정 (첫 화면에 표시됨) |
| 소식·연혁 올리기 | `news:` 맨 위에 `- date:` / `text:` 두 줄 추가 |
| **구성원 논문 진행 단계 갱신** | 해당 구성원의 `step:` 숫자 수정 (1~8). 로드맵 위에 이름표가 옮겨지고 구성원 카드의 "현재 단계"도 함께 바뀜. 아직 논문 과정 전이면 `0` 으로 두고 `stage:` 에 자유 문구 |
| 구성원 연구 주제 입력 | 해당 구성원의 `topic:` 수정 |
| 구성원 한 줄 소개 | 해당 구성원의 `intro:` 에 문장 입력 |
| 구성원 추가 | `members:` 아래 `- name:` 덩어리 하나를 복사해 붙이고 수정 |
| 구성원 삭제 | 해당 `- name:` 덩어리를 통째로 삭제 |
| 졸업생 등록 | `alumni: []` 를 지우고 아래 예시처럼 `alumni:` 목록 작성 |
| 학회 발표·논문 등 성과 | `achievements: []` 를 지우고 예시처럼 `achievements:` 목록 작성 |
| 세미나 요일·시간 | `schedule:` 의 `when:` 수정 |
| 논문 로드맵 단계·시기 수정 | `roadmap:` → 해당 트랙의 `steps:` 에서 `name:` / `when:` / `desc:` 수정 (학교 공지 변경 시) |
| 연구실 비전·운영 원칙 | `vision:` / `principles:` 수정 |
| 교수님 저역서·논문 추가 | `pi:` 아래 `books:` / `papers:` 에 한 줄 추가 (따옴표로 감싸기) |
| 자료실 링크 | `resources:` 의 `url:` 에 주소 입력 (비우면 숨겨짐) |
| 연구실 이름 바꾸기 | `lab:` 아래 `name:` 수정 |

## 논문 로드맵의 단계 번호

| 번호 | 단계 |
|---|---|
| 1 | 논문 과정 선택 |
| 2 | 논문 공개 발표 |
| 3 | IRB 심의 |
| 4 | 표절 검사 (1차) |
| 5 | 논문 심사 (초심) |
| 6 | 논문 심사 (종심) |
| 7 | 표절 검사 (2차) |
| 8 | 최종 논문 제출 |

석사·박사 트랙은 구성원의 `role:` 에 "박사"가 들어 있으면 자동으로 박사 트랙에 표시됩니다.

## 사진 넣기

1. 저장소에서 **Add file → Upload files** 로 사진을 올립니다. 파일 이름은 영문으로 (예: `lee.jpg`, `cheon.jpg`).
2. 올리기 전에 업로드 화면의 경로 칸에 `images/` 를 입력하면 `images` 폴더 안에 들어갑니다. (또는 사진을 루트에 올리고 아래에서 `lee.jpg` 로 적어도 됩니다)
3. `_config.yml` 에서 해당 사람의 `photo: ""` 를 `photo: images/lee.jpg` 로 바꿉니다.

정사각형에 가까운 사진이 가장 잘 나옵니다.

## 주의

- 값에 콜론(`:`)이나 샵(`#`)이 들어가면 따옴표로 감싸세요. 예: `desc: "주제: 마음챙김"`
- 목록 항목은 `- ` (하이픈 + 공백)으로 시작합니다. 들여쓰기 칸 수를 주변과 똑같이 맞추세요.
- 수정 후 홈페이지가 바뀌지 않으면 저장소 상단 **Actions** 탭에서 빨간 X가 있는지 확인하세요. 빨간 X는 `_config.yml` 의 들여쓰기나 따옴표 오류입니다. 방금 고친 부분을 다시 보면 대부분 해결됩니다. 오류가 있어도 홈페이지는 이전 버전으로 계속 보입니다.
- 줌 링크, 회의록 등 비공개 정보는 이 홈페이지에 적지 마세요. 누구나 볼 수 있는 공개 페이지입니다.
